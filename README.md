# ⚽ Sistema de Jogadoras - Projeto Fictício

## Descrição do Projeto 📝
Este é um projeto fictício desenvolvido para gerenciar informações de jogadoras de futebol. O sistema permite **adicionar, visualizar, editar e remover jogadoras**, além de aplicar filtros e ordenações para facilitar a navegação. Todas as informações ficam armazenadas localmente no **LocalStorage**, permitindo persistência entre sessões do navegador.

## Funcionalidades Principais 🚀
### CRUD (Create, Read, Update, Delete)
- **Adicionar jogadora:** Inserção de novas jogadoras com nome, posição, clube, foto e estatísticas.  
- **Editar jogadora:** Atualização das informações existentes de uma jogadora.  
- **Excluir jogadora:** Remoção de jogadoras do sistema.  
- **Favoritar jogadora:** Marcar ou desmarcar jogadoras favoritas para fácil referência.

### Filtros e Ordenação 🔍
- **Busca por nome ou posição:** Filtra jogadoras enquanto você digita.  
- **Filtro por clube:** Exibe apenas as jogadoras do clube selecionado.  
- **Ordenação por nome :** Alterna entre ordem alfabética A-Z e Z-A.  
- **Ordenação por posição:** Organiza jogadoras da goleira ao atacante, ou na ordem inversa.

### LocalStorage 💾
- Todos os dados do sistema são salvos localmente, garantindo que as informações permaneçam mesmo após fechar o navegador.

## Tecnologias Utilizadas 🛠️
- **HTML5** – usado para estruturar a página e organizar o conteúdo.  
- **CSS3** – responsável pelo estilo e layout do projeto.  
- **JavaScript (ES6)** – para a lógica do sistema, incluindo CRUD, filtros e ordenação.  
- **LocalStorage** – armazena os dados das jogadoras no navegador, mantendo as informações mesmo após fechar a página.  
- **FontAwesome** – fornece ícones para os cards e botões, deixando a interface mais visual e intuitiva.
